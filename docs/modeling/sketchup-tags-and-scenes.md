# SketchUp Tags and Scenes

**Protocol:** MD-03  
**Last revised:** November 17, 2026

!!! note "Source and status"
    Imported from the November 17, 2026 conversation export. Its status labels are retained; some earlier decisions were recovered from summaries rather than complete original discussions. Proposed and unresolved material is not adopted office policy.

**Status:** Partially Established; full protocol unresolved

AMA's workflow uses both custom office tags and tags introduced by extensions.

The retained discussion identifies a recurring issue: imported geometry may introduce new tags whose visibility is not appropriately controlled in existing scenes.

## Established concern

Newly imported tags should not unintentionally appear across all documentation scenes.

## Previously considered solution

A SketchUp Ruby operation or extension could disable newly introduced tags across existing scenes.

## Unresolved

- Final office rule for newly introduced tags
- Whether automatic tag visibility management is implemented
- Approved Ruby script or extension
- Required behavior when tags are imported from external models
- Whether ConDoc configuration changes remain necessary

No executable tag-management protocol was finalized in the accessible conversation.
