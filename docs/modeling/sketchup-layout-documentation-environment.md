AMA uses SketchUp and LayOut for architectural drawing production.

The retained workflow also identifies ConDoc Tools as part of the documentation process.

## Documentation organization

SketchUp scenes, tags, and ConDoc configurations support the production of architectural plans, sections, elevations, and other drawing views.

LayOut is used for sheet composition and annotation.
