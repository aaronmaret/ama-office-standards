# LayOut Annotation Maintenance

**Last revised:** November 18, 2026

Because AMA's documentation relies on SketchUp/LayOut, avoid redundant tags and annotations.

Recommended practices:

- Use one primary tagging location for each product category.
- Repeat identifiers only where coordination requires them.
- Maintain consistent references between schedules and drawings.
- Avoid creating unnecessary independent annotation objects that must be updated across multiple views.
