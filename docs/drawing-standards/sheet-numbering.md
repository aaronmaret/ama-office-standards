**Status:** Current series assignments; example numbering is draft

The A0–A9 assignments above are the current AMA office organization. They describe this office's system and do not claim compliance with a separate national sheet-numbering standard.

## Draft sheet format

Use `A` + series digit + two-digit sequence, beginning at `01` within each series. Examples: `A001` for an A0 sheet, `A201` for an A2 sheet, and `A601` for an A6 sheet. Confirm this full-number format before adopting it in an existing project.

| Example | Example sheet title |
| --- | --- |
| A001 | GENERAL INFORMATION |
| A002 | SCHEDULES |
| A101 | SITE PLAN |
| A201 | FLOOR PLANS |
| A301 | EXTERIOR ELEVATIONS |
| A401 | BUILDING SECTIONS |
| A501 | ENLARGED PLANS AND INTERIOR ELEVATIONS |
| A601 | CONSTRUCTION DETAILS |
| A701 | DIAGRAMS |

## Coordination

- Include only the sheets needed for the project; unused series do not require placeholder sheets.
- Keep A8 and A9 unassigned until an office decision establishes their purpose.
- Maintain one coordinated sheet index and verify all view references against it before issue.
- Do not renumber issued sheets without updating the index, references, and issue record.
