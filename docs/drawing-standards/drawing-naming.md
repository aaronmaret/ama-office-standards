# Drawing Title Naming Convention

**Last revised:** November 18, 2026

The convention for naming drawings that have both a drawing type and a designated location or area is:

**Drawing Type – Level, Location, or Area**

The drawing type precedes the level, location, area, or other applicable designation.

## Examples

| Drawing Type | Example Titles |
| --- | --- |
| Floor Plan | Floor Plan – Main Level<br>Floor Plan – Upper Level |
| MEP Plan | MEP Plan – Main Level<br>MEP Plan – Upper Level |
| Reflected Ceiling Plan | Reflected Ceiling Plan – Main Level<br>Reflected Ceiling Plan – Upper Level |
| Framing Plan | Framing Plan – Main Level<br>Framing Plan – Upper Level |
| Finish Plan | Finish Plan – Main Level<br>Finish Plan – Upper Level |
| Enlarged Plan | Enlarged Plan – Kitchen<br>Enlarged Plan – Primary Bathroom |
| Exterior Elevation | Exterior Elevation – North<br>Exterior Elevation – South |
| Building Section | Building Section – AA<br>Building Section – BB<br>Building Section – CC |
| Interior Elevation | Interior Elevation – Kitchen Cabinetry at Refrigerator<br>Interior Elevation – Pantry Shelving |
| Plan Detail | Plan Detail – Post Attachment at C5 |
| Section Detail | Section Detail – Sill at Window Type A |

## “At” Versus “@”

Use “at” to identify a location or condition in drawing titles. Reserve “@” for technical annotations where it has an established meaning, such as spacing.

Use an en dash between the drawing type and its designation. Keep drawing type terminology consistent throughout the set.

## Sheet Titles Versus Drawing Titles

Sheet titles and individual drawing titles may differ.

Example:

Sheet A2.1 — FLOOR PLANS

- Drawing 1: FLOOR PLAN – MAIN LEVEL
- Drawing 2: FLOOR PLAN – UPPER LEVEL

Alternatively:

Sheet A2.2 — MAIN LEVEL PLANS

- Drawing 1: FLOOR PLAN – MAIN LEVEL
- Drawing 2: MEP PLAN – MAIN LEVEL

Both arrangements follow the drawing-title convention.

## MEP Terminology

Use MEP Plan when the drawing genuinely combines mechanical, electrical, and plumbing information.

Use Electrical Plan when the drawing primarily shows receptacles, switches, and related electrical devices.

## Level Terminology

Use consistent terminology throughout a drawing set, such as:

- Main Level
- Upper Level
- Lower Level

Avoid alternating between First Floor, Ground Floor, and Main Level for the same building level.
