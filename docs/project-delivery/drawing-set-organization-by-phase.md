# Drawing Set Organization by Phase

**Last revised:** November 18, 2026

The retained office protocol distinguishes between SD and DD/CD documentation.

## SD

Use a simplified architectural drawing set appropriate to the design phase.

The earlier protocol referenced abbreviated sheet numbering such as:

- A1
- A2
- A3

## DD/CD

Use expanded two-digit sheet identifiers such as:

- A00
- A10
- A20
- A30

The current A0–A9 series assignments govern the categories.

## Unresolved

- Exact minimum deliverables for each phase
- Whether abbreviated SD numbering remains the current preferred practice
- Required DD deliverables
- Required CD deliverables
- Whether the sheet numbering must remain consistent between phases
