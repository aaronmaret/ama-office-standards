# Selections Status Protocol

**Protocol:** SS-17  
**Last revised:** November 17, 2026

!!! note "Source and status"
    Imported from the November 17, 2026 conversation export. Its status labels are retained; some earlier decisions were recovered from summaries rather than complete original discussions. Proposed and unresolved material is not adopted office policy.

**Status:** Established in earlier discussion; current implementation not independently verified

The retained summary identifies these selections statuses:

- Proposed
- Option A
- Option B
- Approved
- Rejected
- Locked

Locked indicates a decision that is effectively irreversible because of production, procurement, or contractual commitment.

## Proposed status colors

| Status   | HEX                    |
| -------- | ---------------------- |
| Proposed | `#DCEAF7`              |
| Option A | `#B8CCF0`              |
| Option B | `#CFE8D5` or `#D6CFF0` |
| Approved | `#A8D5BA`              |
| Rejected | `#D9D9D9`              |
| Locked   | `#6B6B6B`              |

## Superseded or conflicting status information

An earlier selections workflow used:

- Proposed
- Approved
- On Hold
- TBD
- Out for Bid
- Selected
- In Production
- Delivered

The retained discussion later developed the Option A / Option B / Rejected / Locked system.

The final status configuration of the live Google Sheets workbook has not been inspected. The latest conceptual protocol is preserved above, but implementation should be verified before publication as a confirmed software standard.
