# Window Schedule Protocol

**Last revised:** November 18, 2026

## Window identifiers

- `1.01`, `1.02`, etc.
- `2.01`, `2.02`, etc.

## Head alignment

The established default is alignment of finished window head trim with finished exterior door head trim, unless otherwise noted.

This is not simply a requirement to align rough-opening head heights.

## Window type identification

Window types use letters.
