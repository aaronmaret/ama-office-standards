# Door Hardware Schedule

**Last revised:** November 24, 2026

Use numeric hardware groups coordinated with the [Door Schedule](door-schedule-protocol.md). Each door's hardware group refers to the corresponding hardware requirements.

Keep functional door hardware groups distinct from the [Hardware + Accessories Schedule](hardware-accessories-schedule.md), which covers bath accessories, hooks, rods, shelving systems, and similar products.

Standard width: **two horizontal grid modules**. Height varies with content and associated notes.
