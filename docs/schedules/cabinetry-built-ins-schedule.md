# Cabinetry Schedule

**Last revised:** November 24, 2026

Standard width: **two horizontal grid modules**. Height varies with content and associated notes. Drawing tags omit the schedule-ID hyphen: `CB01` references `CB-01`.

## Scope

- Kitchen cabinetry
- Bathroom vanities
- Laundry cabinets
- Pantry units
- Closet built-ins
- Benches
- Window seats
- Media units
- Custom storage

## Schedule Identifiers

- `CB-01`
- `CB-02`
- `BI-01`

## Provisional Columns

`ID | Item | Location | Construction | Finish | Remarks`

## Worked example

| ID    | Item          | Location     | Construction | Finish    | Remarks        |
| ----- | ------------- | ------------ | ------------ | --------- | -------------- |
| CB-01  | Base cabinets | Kitchen      | Semi-custom  | Painted   | See elevations |
| CB-02  | Vanity        | Primary Bath | Custom       | White oak | Wall-hung      |
| BI-01 | Storage bench | Mudroom      | Custom       | Painted   | See elevation  |

## Recommended rules

- Identify cabinet groups and built-in assemblies.
- Avoid scheduling every cabinet box unless necessary.
- Use architectural elevations to control dimensions and configurations.
- Use approved shop drawings for fabrication details when applicable.
