# Cabinetry + Built-ins Schedule

**Last revised:** November 18, 2026

## Scope

- Kitchen cabinetry
- Bathroom vanities
- Laundry cabinets
- Pantry units
- Closet built-ins
- Benches
- Window seats
- Media units
- Custom storage

## Identifiers

- `CB01`
- `CB02`
- `BI01`

## Proposed columns

`ID | Item | Location | Construction | Finish | Remarks`

## Worked example

| ID    | Item          | Location     | Construction | Finish    | Remarks        |
| ----- | ------------- | ------------ | ------------ | --------- | -------------- |
| CB01  | Base cabinets | Kitchen      | Semi-custom  | Painted   | See elevations |
| CB02  | Vanity        | Primary Bath | Custom       | White oak | Wall-hung      |
| BI01 | Storage bench | Mudroom      | Custom       | Painted   | See elevation  |

## Recommended rules

- Identify cabinet groups and built-in assemblies.
- Avoid scheduling every cabinet box unless necessary.
- Use architectural elevations to control dimensions and configurations.
- Use approved shop drawings for fabrication details when applicable.
