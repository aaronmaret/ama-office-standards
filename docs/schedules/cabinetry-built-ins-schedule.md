- Kitchen cabinetry
- Bathroom vanities
- Laundry cabinets
- Pantry units
- Closet built-ins
- Benches
- Window seats
- Media units
- Custom storage

## Recommended rules

- Identify cabinet groups and built-in assemblies.
- Avoid scheduling every cabinet box unless necessary.
- Use architectural elevations to control dimensions and configurations.
- Use approved shop drawings for fabrication details when applicable.
